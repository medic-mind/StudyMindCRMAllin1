# StudyMind All in One CRM

A single pane of glass for everything StudyMind does - every email, call, message, payment, booking, task, and AI insight about every parent, student, tutor, and Local Authority contact, in one place. Built as a Next.js 15 + TypeScript + Prisma + Clerk + tRPC monorepo on Railway.

For everything else - architecture, integrations, golden rules, RBAC, GDPR, on-call, and how to contribute - read [CLAUDE.md](./CLAUDE.md). It is the source of truth.
